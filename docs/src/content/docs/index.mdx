<div class="lg-features not-content">
  <div class="lg-feature">
    <h3>Exact</h3>
    <p>Raw scores and probabilities equal the library's <code>predict</code> bit for bit: NaN and zero-as-missing, categorical splits, XGBoost's float32 arithmetic and CatBoost's CTRs included. What the notebook showed is what production returns.</p>
  </div>
  <div class="lg-feature">
    <h3>Fast to predict</h3>
    <p>A binned interpreter for any batch size, and a compiled mode that turns LightGBM and XGBoost trees into native code in a few seconds. <code>autotune</code> picks the faster one for your data.</p>
  </div>
  <div class="lg-feature">
    <h3>CatBoost with categories</h3>
    <p>Categorical features, one-hot and CTRs with their combinations, straight from strings in pandas, Arrow or plain lists. No preprocessing, no compilation.</p>
  </div>
  <div class="lg-feature">
    <h3>Fast to start</h3>
    <p><code>model.save("model.bin")</code> writes a file that maps into memory in well under a millisecond; compiled trees ship next to it, so production needs no compiler.</p>
  </div>
  <div class="lg-feature">
    <h3>Arrow in, no copies</h3>
    <p><code>predict</code> reads pyarrow, polars and any Arrow PyCapsule data directly. C and C++ services pass Arrow record batches through the C API.</p>
  </div>
  <div class="lg-feature">
    <h3>Small and portable</h3>
    <p>One C++20 library with no dependencies beyond simdjson and OpenMP. Wheels for Linux, macOS and Windows on x86-64 and ARM.</p>
  </div>
</div>
