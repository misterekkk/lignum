## Notes

- Timings are end to end from a NumPy float64 array: they include TL2cgen's `DMatrix` construction and the float32 copy ONNX Runtime needs.
- lleaves compiles for the host CPU by default; lignum and TL2cgen were built without `-march/-mcpu=native`.
- `tl2cgen-tuned` = `quantize=1` + branch annotation computed on the training data.
- ONNX Runtime evaluates trees on float32 inputs, so LightGBM models take different paths for some rows (max diff 6.9e-4).
- lleaves and TL2cgen/GTIL on XGBoost differ in the last bits (summation order / float64 accumulation); lignum is bit-identical on every row.
- The M4 has 4 performance + 6 efficiency cores.
